# Lactobacillaceae ARG

Selected analysis and plotting code for antibiotic resistance genes (ARGs) in Lactobacillaceae. Scripts and processed input tables are organised by figure under `analysis/`.

- [Fig1](analysis/Fig1/) — ARG carriage and resistance classes.
- [Fig2](analysis/Fig2/) — Taxonomic structure and genus-level ARG prevalence.
- [Fig3](analysis/Fig3/) — MGE associations and cross-species ARG sharing.
- [Fig4](analysis/Fig4/) — ARG distribution across plasmid taxonomic units (PTUs).
- [Fig5](analysis/Fig5/) — Source-associated and within-species ARG variation.
- [Fig6](analysis/Fig6/) — Accessory-genome effect-size summaries.
- [FigS2](analysis/FigS2/) — Source-balanced resampling.
- [shared/data](analysis/shared/data/) — Input tables shared across analyses.
